Flat PWA package for the secondary advanced Danco prototype.

- Danco Workforce Assessment / Apply to work at Danco journey choice.
- Device mode locking by administrator.
- English / Spanish application, DISC/work-style primer and role-specific assessment.
- Roofing progression assessment plus Commercial Account Manager sales-suitability assessment.

- Employment contract generation and Employment contracts filing.
- Private upload-only Signed employment contracts workflow.

## Deploy
Upload all files to the root of a dedicated GitHub Pages repository. Keep this advanced build separate from the standard Danco prototype.

GitHub Pages: Settings > Pages > Deploy from a branch > `main` > `/ (root)`.

## Prototype privacy
Do not enter a real Social Security number during a public demonstration. Use `PROTOTYPE`.

The ordinary Danco applicant record strips raw SSN values and stores only identity-readiness metadata / last four digits when structurally valid. Signed contracts are designed for private Supabase Storage rather than public GitHub assets.
