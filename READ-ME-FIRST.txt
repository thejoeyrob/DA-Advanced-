TEST THE NEW ROUTING

2. Select English or Spanish.
3. If the device is in Choice mode, select either:
   • Danco Workforce Assessment
   • Apply to work at Danco
4. In Administrator, use Device Start Mode to lock the device to either route or restore Choice of either.

TEST THE SSN WORKFLOW SAFELY
For prototype demonstrations, enter PROTOTYPE in the Social Security number field. Do not enter a real applicant SSN into a public demonstration build.

If an invalid or blank SSN is used, the applicant can proceed only after acknowledging the warning and selecting a reason. That application can still be stored and reviewed, but the administrator cannot request a background check from it.

BACKGROUND CHECK RULE
If no valid SSN readiness is present, the administrator receives:
“Unable to request a background check on this applicant due to no Social Security number being provided. Danco does not recognise or accept no Social Security number background checks.”

PROTOTYPE bypass is accepted only for the demonstration background workflow. It must never satisfy a live CRA request.

SUBMISSION
Applicants can now submit completed applications directly to the protected shared review list without knowing the administrator PIN. Administrator access and background-screening actions remain protected.

PRIVACY
The normal Danco applicant record does not retain a full raw SSN. It stores high-level SSN readiness, masked last four digits for a structurally valid number, prototype-bypass state, and any exception reason. A future live CRA integration requires a separately approved secure identity handoff/provider flow.
