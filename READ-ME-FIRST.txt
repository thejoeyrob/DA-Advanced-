WHAT IS NEW
• Commercial Account Manager application option.
• Same five-question work-style primer, followed by a dedicated timed ten-question commercial-sales suitability assessment.
• Private administrator report with 0–100% suitability, commercial indicators and estimated sales approach.
• Applicant background-screening consent question and refusal-reason capture.
• Admin-only Request background check button after result review.
• Demonstration cost-approval screen before screening request.
• Supabase-stored screening demonstration record with placeholder result categories.
• Additional queues: CB checked · To action, CB checked · Eligible and CB checked · Not eligible.

FIRST REVIEW
1. Unlock the trial.
2. In Administrator, choose Application mode.
3. Start a new applicant and select Commercial Account Manager.
4. Complete the work-style primer and ten timed sales questions.
5. Submit the application to the shared database.
6. Open Administrator and load the application report.
7. Select Request background check.
8. Review the demonstration cost screen, approve it, and submit.
9. The record moves to CB checked · To action and placeholder screening results appear in the report.
10. Manually file it as Eligible, Not eligible, or leave it To action.

IMPORTANT
The background screening is a demonstration only. The Eligible / Not eligible folders are manual administrative workflow states, not an automated employment decision.
